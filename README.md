# 📊 stock – 財務資料視覺化工具（Flask + Chart.js + yfinance）

一個使用 Flask 框架製作的簡易網站，搭配 [yfinance](https://pypi.org/project/yfinance/) 擷取公司財務資料，並以 Chart.js 呈現近三年的淨利（Net Income）變化。

## 🚀 專案特色

- 🔍 使用者可以輸入公司股票代碼（如：AAPL、TSLA）
- 📈 即時查詢該公司近三年的淨利數據
- 🎨 使用 Chart.js 繪製互動式長條圖
- 🐍 後端以 Python + Flask 撰寫
- 📡 整合 yfinance 自動擷取財報資料

## 🧰 使用技術

- [Python 3.x](https://www.python.org/)
- [Flask](https://flask.palletsprojects.com/)
- [Chart.js](https://www.chartjs.org/)
- [yfinance](https://pypi.org/project/yfinance/)
